# DM Forge — Помощник для проведения D&D партий (DM Screen Only)

Автономное кроссплатформенное настольное приложение на базе **C++17 и Qt 6**, предназначенное исключительно для Мастера Подземелий (Dungeon Master) при проведении настольных ролевых игр D&D 5e.

## Ключевые особенности
- **DM Screen Only:** закрытый интерфейс, с которым работает только Мастер; игроки не видят экран программы и не взаимодействуют с ней.
- **Трекер боевой сцены:** очередь инициативы, контроль HP, классов доспеха, состояний и автоматический расчёт сложности спасбросков концентрации.
- **Режиссёр боя и анализатор накала (`Live Tension & Encounter Director`):** расчёт индекса напряжённости сражения в реальном времени по скользящему окну DPR за 3 раунда и система сценарных триггеров.
- **Локальный бестиарий и скрытые броски:** фильтрация существ по CR и типу, генератор бросков `d4`–`d100`, атомарное автосохранение сессии и экспорт хроники боя в Markdown/JSON.

## Структура проектной документации (ЛР №3 и ЛР №4)
- `srs/srs-template.md` — Спецификация требований к ПО (`SRS v0.2`).
- `sdd/sdd-template.md` — Описание дизайна программного обеспечения (`SDD v0.2`, стандарт IEEE 1016) с матрицей приоритезации функционала (10–50) и проектными представлениями.
- `adr/adr-template.md` — Протоколы архитектурных решений (`ADR-001` — `ADR-003`).
- `docs/communication/communication.md` — Протокол двух раундов ролевых переговоров с Заказчиком, эволюция итерационного плана и расчёт бюджета.
- `images/dmforge-architecture.png` — Диаграмма компонентов и слоёв приложения (`DMForge.UI`, `DMForge.Core`, `DMForge.Infrastructure`).
- `images/dmforge-classes.png` — Диаграмма классов логической модели данных и контрактов сервисов.
